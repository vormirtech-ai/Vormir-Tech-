  MedV - Pharmacy Management
  by Vormir Tech Solutions, Nagpur
==========================================================

WHAT THIS IS
  A complete medical-store application: counter billing,
  batch/expiry inventory, purchase entry with Excel import,
  GST returns, patient & supplier ledgers, refill reminders,
  reports and local backup.

  Your data never leaves the computer it is typed on.


==========================================================
  THE EASY WAY - THE WEB EDITION  (nothing to install)
==========================================================

  Open this link in Chrome or Edge:

      https://vormirtech-ai.github.io/Vormir-Tech-/medv/

  That is it. No Node.js, no npm, no installer, no Windows
  security warnings. It works offline after the first visit.

  To get a desktop icon: open the link, then click the
  INSTALL icon in the address bar. MedV then opens in its
  own window like any other program.

  (If the link does not work yet, the branch has not been
   merged into main. See docs\WEB-HOSTING.md - it is a
   two-minute, one-time setting on GitHub.)

  IMPORTANT with the web edition: the data lives inside that
  browser on that computer. Never use a private/incognito
  window, and download a backup to a pen drive every day
  (Backup -> Download backup).


==========================================================
  THE OTHER WAY - THE WINDOWS DESKTOP APP
==========================================================

  Only if you want an installed .exe. Needs Node.js once,
  on a machine with internet.

  0. Right-click the zip -> Properties -> tick "Unblock",
     then right-click again -> "Extract All..." to C:\MedV
     (Do NOT run anything from inside the zip preview window.)

  1. Install Node.js LTS from https://nodejs.org

  2. Open the extracted folder, click the address bar,
     type  cmd  and press Enter. Then run:

         npm install
         npm run dist

  3. You now have:
         dist\MedBillPro_Setup.exe

  If Windows blocks anything, read docs\WINDOWS-SECURITY.md
