WHAT THIS IS
  A complete medical-store application: counter billing,
  batch/expiry inventory, purchase entry with Excel import,
  GST returns, patient & supplier ledgers, refill reminders,
  reports and local backup.

  All data is stored in ONE SQLite file on this computer:
      %APPDATA%\MedBillPro\data\medbill.db
  No cloud. No server. No internet needed to use it.


STEP 0 - UNBLOCK, THEN *EXTRACT*  (30 seconds, saves an hour)

  a) Right-click MedV_MedBillPro_v1.0.0.zip -> Properties
         -> tick "Unblock" at the bottom -> OK
     Windows marks everything inside a downloaded zip as
     "from the internet" and then refuses to run it.

  b) Right-click the zip again -> "Extract All..."
         -> extract to a short path such as   C:\MedV

  DO NOT run anything from the window that opens when you
  just double-click the zip. That window is a preview: if you
  launch a file from it, Windows copies THAT ONE FILE into a
  temporary folder and leaves the other 78 behind, so the
  build fails with "Could not read package.json".

  Already extracted? Right-click the folder -> Open in
  Terminal -> run:   Get-ChildItem -Recurse | Unblock-File


HOW TO GET IT RUNNING (Windows)
  1. Install Node.js LTS once, from https://nodejs.org
     (needed only to build the installer - the finished
      application never uses the internet).

  2. Open the EXTRACTED MedV folder (C:\MedV\MedV) in
     Explorer, click the address bar, type  cmd  and press
     Enter. Then run:

         npm install
         npm run dist

     (Or double-click build-windows.bat, which runs the
      same two commands. If Windows Smart App Control
      blocks the .bat, use the two commands above - typing
      them yourself is never blocked.)

  3. When it finishes you will have:
         dist\MedBillPro_Setup.exe      <- the installer
         dist\MedBillPro_Portable.exe   <- no-install version

  4. Run MedBillPro_Setup.exe on the shop computer,
     then start MedV from the desktop icon and complete
     the 3-step setup wizard.

  Just want to look at it first?   npm install   then   npm start


IF WINDOWS BLOCKS SOMETHING
  The installer is not code-signed, so Windows 11 may stop it.
  docs\WINDOWS-SECURITY.md explains every dialog and how to
  get past it - including "Smart App Control blocked a file",
  which has no "Run anyway" button.
